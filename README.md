# KAI releases

Release artifacts for **KAI** — the voice-controlled AI co-pilot for streamers.

This repository hosts **installers only**; the source lives elsewhere. The
desktop app's updater reads `latest.json` from the newest published release.

Downloads are under **Releases**. Verify an installer before running it:

```
certutil -hashfile KAI_x64-setup.exe SHA256
```
